# mephi-session-project-2026

## 1. Установка дистрибутива

1.1. Сеть настроена при установке ОС: адрес интерфейса выдаётся по DHCP.

1.2. Имя хоста задано при установке ОС.

1.3. Связь с внешней сетью проверена командой `ping -c 4 8.8.8.8`.

## 2. Управление программным обеспечением

2.1. Пакеты дистрибутива обновлены: `dnf update -y`.

2.2. Из репозиториев установлены nginx, libcap-ng-utils и dnf-plugins-core:

`dnf install -y nginx libcap-ng-utils dnf-plugins-core`

2.3. RPM-пакет tcpdump скачан через dnf и установлен командой rpm.

## 3. Управление файловыми системами

3.1. Второй диск подключён при создании виртуальной машины. В командной строке раздел отформатирован в ext4, метка тома — `MEPHI_WEB`.

## 4. Управление сервисами

nginx запущен. Сообщения сервиса сняты через journalctl.

## 5. Управление доступом

Создан каталог `/data/mephi-2026`, заведены пользователи и группы, права выставлены по заданию. SELinux работает в режиме Enforcing.

## 6. Аутентификация

Кураторы не могут войти в систему локально. Пароль не короче 12 символов, менять его нужно каждые 90 дней.

## 7. Тестирование

`curl` открывает страницу и показывает номер.
